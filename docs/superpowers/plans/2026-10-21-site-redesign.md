# 整站重设计：统一为「动捕棚」风格

> 日期：2026-10-21 · 状态：执行中
> 前置：stage 文章系统已上线（`2026-10-20-stage-article-system.md`）

## 已确认的决定

| 项 | 决定 |
|---|---|
| 主题 | 深色为主 + 浅色「日光棚」变体；默认跟随系统，顶栏开关可手动切换并记住选择 |
| 首页首屏 | 文章标记点星图：每篇文章一个荧光标记点，按时间 × 板块排布，同板块连成「骨架」，悬停看标题、点击进入 |
| 开场校准动画 | 首页首访 + stage 文章；同一会话只播一次（共用 sessionStorage 键） |
| 普通文章目录 | 从正文 h2/h3 自动生成左侧目录与阅读刻度；标题少于 2 个的短文不显示 |

## 策略：以样式重写为主，结构重构只做首页

- 现有 class 名（日报卡片、开源雷达、对话气泡、日历……）大多由脚本生成，保持不变，只重写样式——不碰内容生成逻辑，风险最小。
- 全站共用一套设计 token（与 stage 文章同源），明暗两套取值。
- 首页是门面，重写结构和模板。

## 守住的底线

- 内容和 URL 不变：所有现有页面地址保持可访问，RSS 不变。
- 无 JS / 减弱动效时内容完整可见（沿用 `html.m-on` 约定）。
- 明暗两套主题都满足正文对比度 ≥ 4.5:1。
- 主题选择只存在浏览器本地（localStorage，读写包 try/catch，失败时退回跟随系统）。
