# 动效

实现：`static/stage/motion.js` + `motion.css`。**作者通常什么都不用做**——写对原稿结构，动效就自动挂上。

## 原则

1. **先找隐喻，再选动效。** 动捕棚的每个动效都来自同一个世界：标记点、时间码、对焦、取景框、扫描、追踪。动效在讲主题，而不只是装饰。
2. **首屏浓烈，正文克制。** 首屏可以有约 2.5 秒的编排；正文元素只播一次，≤ 600ms，不打断阅读——这是给反复复习的人用的页面。
3. **每屏最多一个主动效。** 两个东西同时抢注意力，等于都没有。
4. **静态版也必须完整。** 所有初始隐藏状态都挂在 `html.m-on` 下；减弱动效、JS 失败（5 秒兜底）时，页面就是完整的静态版。

## 自动挂载的动效

| 编号 | 动效 | 由什么触发 |
|---|---|---|
| M0 | 相机校准开场（约 1.1 秒，会话内一次，点击 / 任意键跳过） | 首次打开页面 |
| M1 | 标记点成形：首屏标题逐字由荧光点长成字形 | 首屏 `h1` |
| M2 | 时间码滚动：数字乱跳后逐位锁定 | 章节头 `[00:01:20]` |
| M3 | 对焦：章节标题逐字由模糊变清晰，左侧闪过对焦框 | `## ` 章节标题 |
| M4 | 扫描线擦除 | `::: tldr` |
| M5 | 荧光划线 | 正文段落和列表里的 **加粗** |
| M6 | 取景框锁定：四角收拢，REC 闪两下 | 每个 `::: interactive` 模块 |
| M7 | 镜头推拉：滚动时首屏后退变暗 | 首屏 |
| M8 | 追踪括号：括号锁定后斜体部分变荧光 | `::: quote` |
| M9 | 数字滚动 | `::: stats` 数值里的整数 |
| M10 | 章节刻度：目录每节下方的阅读进度 | 自动 |

正文段落、列表、模块外壳还有一次轻微上浮（`m-rise` / `data-reveal`）。

## 想为一篇文章定制动效

- **组件内部**的动效写在组件里（见 widget-contract.md），用 `onceVisible` 做入场编排，用 `whileVisible` 做持续动画。
- **首屏**换成本文专属的 hero 组件（见 components.md）。
- 不要在本文 `style.css` 里覆盖 `motion.css` 的全局规则；需要新的全站动效原语，应该提议加进 `motion.js` 并征得用户同意。

## 技术约束

- 只动 `transform` / `opacity` / `clip-path` / `filter`。
- 新的初始隐藏状态必须写成 `html.m-on .xxx{…}`。
- 拆字后每个字都是 `span.ch > span.gl`：给标题里的局部元素写样式时用专门的类（例如 `.hl`），不要写 `h1 span`——会命中每一个字（真实踩过的坑）。
- 不用 `innerHTML`。
