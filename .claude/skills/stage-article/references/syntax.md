# 原稿语法全集

实现：`src/stage.py`（渲染）、`src/csdn_stage.py`（CSDN 展开）。写法有误时，`drafts.py publish` 和生成器都会报出行号并停止，不会静默丢内容。

## 目录

1. 文件布局
2. frontmatter
3. 章节标题
4. 指令块总则
5. 各指令及其 CSDN 输出

## 1. 文件布局

文件夹文章（推荐）：

```
content/<板块>/<slug>/
├── index.md       # 原稿
├── widgets.js     # 可选：本文专属组件
├── style.css      # 可选：本文专属样式
└── fig.png ...    # 可选：图片等资源
```

- 页面地址 `/<板块>/<slug>.html`，资源地址 `/<板块>/<slug>/<文件>`。
- 正文里的相对路径（`![](fig.png)`）会自动改写到资源目录，个人站和 CSDN 都能显示。
- 只发布白名单类型：js mjs css json png jpg jpeg webp avif gif svg mp4 webm mp3 woff2 pdf glb gltf；点文件和其他类型（如草稿 .md、.py）不会发布。

单文件文章（`content/<板块>/<日期>-<名字>.md`）也可以用 `design: stage`，但不能带专属组件和资源。

## 2. frontmatter

```yaml
---
title: 完整标题：可带副标题
display_title: 首屏短标题，[高亮词]用方括号
date: 2026-10-20            # publish 时自动改成当天
section: docs               # 只在草稿里用，决定发布到哪个板块
summary: "一两句摘要"
tags: [AI, 3D]
kicker: 技术文档 / 3D · 计算机视觉
source: "https://..."
source_label: 频道或作者简称
design: stage               # 必须
hero: mocap-gait            # 可选：首屏组件，默认 mocap-gait
---
```

`design: stage` 不能与 `html: true` 或对话格式（`type: chat`、ai-chat 板块）同时使用。

## 3. 章节标题

| 写法 | 页面 | 目录 | CSDN |
|---|---|---|---|
| `## [01:20] 标题` | 时间码 `[00:01:20]` | `01:20` | `## 标题 · 01:20` |
| `## [1:02:03] 标题` | `[01:02:03]` | `01:02:03` | `## 标题 · 1:02:03` |
| `## [note] 标题` | `[NOTE]` | `NOTE` | `## 标题` |
| `## 标题` | `[§03]` | `§03` | `## 标题` |

- 只有 `##` 是章节；`###` 渲染为小节标题（`// ` 前缀），不进目录。
- 章节 id 依次为 `c1`、`c2`……，CSDN 的「交互版见原文」链接会指向组件所在章节的锚点。
- 代码块和指令块里的 `##` 不算章节。

## 4. 指令块总则

```
::: 名字 参数
内容（Markdown）
:::
```

- 开头和结尾各占一行；结尾就是单独的 `:::`。
- 不能嵌套；代码块（``` 或 ~~~）里的 `:::` 不当作指令。
- 只有 `interactive` 接受参数；参数写成 `key="value"`，值必须加双引号，键可以用大小写字母、数字、`_`、`-`。

## 5. 各指令

### interactive——交互组件

```
::: interactive 组件名 title="模块标题" hint="DRAG / ← →" note="模块下方的一句提示" 其他="props"
降级内容：一段能独立阅读的文字 / 表格 / 列表。通用组件从这里读数据。
:::
```

- `组件名`：小写字母、数字、连字符。先找本文 `widgets.js` 里的同名组件，再找组件库。
- `title`：模块头标题，也会出现在 CSDN 的「本节有交互演示「title」」里——写中文。
- `hint`：模块头右侧的操作提示，等宽小字。
- `note`：模块下方说明，支持行内 Markdown。
- 其余属性原样作为 `ctx.props` 传给组件（字符串）。
- CSDN：降级内容 + `> ▶ 本节有交互演示「title」……[打开交互版](原文#cN)`。

### tldr——一句话结论

```
::: tldr
结论，可以有 **加粗**。
:::
```
CSDN：`> **一句话结论**：……`

### quote——全文最重要的一句

```
::: quote
整个难题只剩一件事：*在每一帧里找到每一个关节*。
:::
```
斜体部分在页面上锁定为荧光高亮。CSDN：`> **……**`

### ledger——结果账本

```
::: ledger
- [+] **适用范围** 一句话。
- [-] **局限 1** 一句话。
- **中性项** 不带符号也可以。
:::
```
每项必须以 `**标题**` 开头且写在一行内。CSDN：`- ✔ / - ✘` 列表。

### lessons——方法论

```
::: lessons
1. **原则标题。**为什么它在别处也成立。
:::
```
CSDN：原样的编号列表。

### stats——数据卡

```
::: stats
- TIME / MONSTER | ~~4d~~~min | 每只怪物的处理时间
- SYNTH FRAMES | 3000 | 张合成渲染
:::
```
三列：标签 | 数值 | 说明。`~~x~~` 渲染为删除线（表示「从 x 变成……」）；数值里的整数会在页面上做计数动画。CSDN：三列表格。

## 6. 常见报错

| 报错 | 原因 |
|---|---|
| `::: x 没有用单独一行 ::: 结束` | 忘了结尾行 |
| `指令不能嵌套` | 在指令块里又开了指令 |
| `多余的 :::` | 多写了一个结尾 |
| `代码块没有结束` | ``` 没有闭合（会吞掉后面所有内容） |
| `参数 'title=foo' 格式不对` | 值没加双引号 |
| `多余的参数` | 组件名后面跟了不是 key="value" 的词 |
| `不是列表项（每一项必须写在一行里）` | ledger / lessons / stats 里有续行或段落 |
| `组件名 ... 不合法` | 用了大写或路径字符 |
| `未知指令` | 拼错，可用：interactive tldr quote ledger lessons stats |
